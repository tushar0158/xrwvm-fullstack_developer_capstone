# xrwvm-fullstack_developer_capstone

## Project Name: fullstack_developer_capstone

Best Cars Dealership is a full-stack web application built with Django and React as part of the IBM Full Stack Software Developer Capstone. Users can browse car dealerships across the United States, view dealer reviews, and post their own reviews after logging in.

## Repository Details
- **Repository name:** xrwvm-fullstack_developer_capstone
- **Project name:** fullstack_developer_capstone

## Tech Stack
- Backend: Django, Python
- Frontend: React, HTML, Bootstrap
- Database: SQLite (development)
- CI/CD: GitHub Actions
